# Python Simple Calculator 🧮

A simple, clean and user-friendly calculator built with Python. Perfect for beginners to understand Python basics.

## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Clean and simple code

## 🚀 How to Run
1. Clone this repository:
```bash
git clone https://github.com/tayyabajaved441-stack/Python-Simple-Calculator.git
```
## 💻 Example  
 Enter first number: 10   
 Enter operation (+, -, *, /):+    
 Enter second number: 5   
 Result: 15
